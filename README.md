# The World in 10

**The world explained, one story at a time.**

Production repository for *The World in 10* — a daily English-language global
news briefing for YouTube.

- **Format:** 12–15 minute episodes, neutral documentary narration
- **Schedule:** Daily, target 9:00 AM WIB (UTC+7)
- **Visual identity:** Modern digital newsroom — dark navy, white typography,
  cyan/electric-blue accents, maps, timelines, data visualizations

## Repository structure

```
episodes/   — one production package per episode (script + YouTube deliverables)
assets/     — reusable templates (thumbnail, lower-thirds, chapter format)
```

## Episode package contents

Each episode file contains the complete production package:

1. Three title options + recommended title
2. Thumbnail concept (2–4 words of text)
3. Full narration script (~1,600–2,000 words)
4. Scene-by-scene visual plan
5. SEO-friendly video description
6. Chapters with timestamps
7. Keywords and hashtags
8. Sources with URLs and publication dates
9. Editorial quality-control checklist

## Editorial standards

- Verify major claims through multiple independent sources; prefer official
  documents, direct statements, and established international news organizations.
- Distinguish verified facts from allegations, estimates, and forecasts.
- Never invent quotations, statistics, sources, or events.
- Respect copyright: summarize in original language, add independent context.
- No misleading thumbnails, fabricated urgency, or synthetic footage presented
  as real. Disclose AI-generated visuals per YouTube policy.
